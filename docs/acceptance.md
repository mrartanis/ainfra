# Приёмка

Проверки пока pending; результаты дополняются фактическими командами.

- Ingestion: scopes, duplicates/conflicts, sequence, partial/complete, timestamps, manual ownership.
- Persistence: transactions, migrations, FTS5, reopen, backup/restore.
- Inventory: nodes, relations, services, documents/revisions, approvals, payment/backup.
- Collectors: настоящие dpkg/APT; network/resources; WG без secrets; checks; RouterOS protocol.
- CVE: реальные Debian/Canonical feeds; source/version/release/origin; outage retention; Debian differential comparator.
- UI/CLI: отдельный процесс; API-only; mobile/desktop, поиск, context/export.
- Distribution: static Linux amd64/arm64, macOS CLI; checksums, systemd, docs.
- Security: token isolation, revocation, body bounds, escaping/CSRF, secret leakage, race.
- Внешние серверы/RouterOS: not run — доступы не предоставлены; локальный запуск требуется.
