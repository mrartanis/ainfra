# Будущие расширения

MCP не входит в текущий runtime. Возможный будущий stdio adapter должен обращаться к тому же versioned HTTP API, использовать отдельный reader token по умолчанию и сохранять ограничения editor/admin. Не открывать отдельный remote transport или прямой доступ к SQLite. Текущие CLI и skill уже позволяют получить контекст и сохранить черновик без LLM backend внутри сервиса.

Вне scope: установка обновлений, удалённое исполнение команд, управление конфигурациями, универсальный vulnerability scanner и оценка runtime/livepatch. Локальные check_commands — доверенные скрипты оператора; они не регистрируются через API или документы.
